# 素材来源与整理方式

## 舰船图库

随附图库由维护者提供的官方图片缓存整理，包含 256 张原图及逐张对应的 WebP 缩略图。`assets/ships/manifest.json` 保存用于初始化的舰船中英文名称、美元价格、图片文件名和校验信息。价格与名称为 2026-10-20 整理快照，未经实时官方校价。

缩略图由本项目的 `thumbnails.mjs` 使用 sharp 从原图生成：保持比例、不放大，最大 480 × 320 像素，WebP 质量 72。浏览图库时使用缩略图，合成预览与导出使用选中的原图。

未包含用户提供的商品图样例、示例图片中的店铺标识、个人账号或留言数据。完整权利说明见 [ASSET_LICENSE.md](../ASSET_LICENSE.md)。

## 中框背景

以下三个背景通过 AI 图像生成工具为项目创作，再由 Canvas 绘制文字、边线、切角及布局：

| 文件 | 创作方向 |
| --- | --- |
| `public/assets/naval.png` | 深海蓝、轻微烟蓝氛围、边缘低对比几何平面 |
| `public/assets/porcelain.png` | 瓷白、浅灰纸面折线、低饱和香槟灰边缘 |
| `public/assets/graphite.png` | 哑光石墨灰、宽幅烟灰斜面、克制的边缘亮度 |

创作参考为 RSI 官方网站的配色、留白与排版气质；生成要求排除舰船、官方标志、文字、发光装甲、线路及繁复装饰。它们是无文字背景材质，不是从参考网站截取的界面或官方美术。

箭头使用保留来源及许可的 Lucide SVG 路径，详见 [第三方说明](../THIRD_PARTY_NOTICES.md)。
