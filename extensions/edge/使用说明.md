# 星际公民CCU图片生成器 · 离线扩展使用说明

## 安装和打开

以下步骤适用于 Release 中的完整扩展安装包。如果下载的是仓库源码，须先在仓库根目录执行 `npm ci`、`npm run build:edge`，然后加载生成的 `dist/edge`；不要直接加载源码中的 `extensions/edge` 目录。

请使用 `WB-image-generator-Edge-offline-1.0.2.zip` 或更新版本；1.0.2 的扩展显示名称为「星际公民CCU图片生成器」。此前 1.0.1 已修复商店上传的多份 `manifest.json` 及 ZIP 根目录结构问题，并通过商店包验证。包内图库清单为 `assets/ships/catalog.json`，唯一的 `manifest.json` 位于 ZIP 根目录；同一个包既可供商店上传，也可解压安装。不要再上传 1.0.0 旧包。尚未在真实 Edge 中完成试装，也尚未通过商店审核或上架。

1. 将扩展完整解压到准备长期保留的目录，确认解压目录直接包含 `manifest.json`。
2. 在 Microsoft Edge 中打开 `edge://extensions`。
3. 开启「开发人员模式」，点击「加载解压缩的扩展」。
4. 选择本文件所在目录，确认其中有 `manifest.json`。
5. 点击 Edge 工具栏扩展菜单中的「星际公民CCU图片生成器」。工作台在新标签页打开。

安装方式参见 [Microsoft 官方说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)。不需要另启本地服务器或登录网站账号。

## 生成一张商品图

1. 选择起点和终点舰船。列表会根据另一端价格过滤，起点必须严格低于终点；未知价格的舰船需先填写价格。
2. 选择 WBCCU、涨价 CCU 或普通 CCU，按需调整上下排列。
3. 填写店铺名称，选择中框，修改中框文字或切换到单独箭头模式。单独箭头可选择样式与颜色。
4. 根据预览调整图片位置、缩放和商品标题，选择尺寸及格式后导出。

中框「底＋文字」模式可定制文字与箭头；「单独箭头」模式不绘制文字底板，保留箭头样式和颜色设置。舰船左上角的美元价格来自舰船资料。

## 批量生成

在「外部导入」中上传 CSV 或 XLSX 文件，先检查匹配结果，再选择输出语言并生成 ZIP。默认使用中文舰船名称；选择英文时使用英文名称。无法唯一匹配的舰船需按界面提示选择。

| 来源 | 读取位置 | 路线与类型字段 |
| --- | --- | --- |
| CCUgame CSV | 首行表头，UTF-8 编码 | `from`、`to`、`saving` |
| 星河避难所 XLSX | 第一个工作表；首行标题，第二行表头 | 起始船、终点船、节约；也识别相应中英文船名列及带美元符号的节约列 |

`saving` / 节约为 0 时生成普通 CCU，否则生成 WBCCU。批量生成沿用当前店铺、中框、尺寸和格式，商品标题按路线自动生成，仍须满足严格低价到高价的条件。

单个表格不超过 5 MB，单次不超过 5000 行。生成结果约每 100 MB 分一包；先下载当前 ZIP，再继续下一包，继续操作会清除上一包的下载链接。表格解析、原图读取、合成及打包均在本机完成；耗时和内存占用取决于本机配置、图片尺寸与行数。

## 维护本机图库

在舰船图库中添加图片、编辑名称和价格、替换图片或删除舰船。支持 JPG、PNG、WebP，可同时添加多张。文件名使用 `舰船名称-价格.jpg` 可自动识别名称与美元价格，例如 `Ares Ion-250.jpg`；价格可随后手动修改。

内置 256 张原图与 256 张缩略图：列表使用本地缩略图，预览和导出使用所选舰船原图。新增图片和修改记录仅影响当前 Edge 用户配置文件中的本机图库。

本包约 267 MB；首次下载和解压占用流量及磁盘，安装后常规使用无需从生成器服务器下载图片。内置资料为 2026-10-20 整理快照，不会自动联网更新。

## 配置、更新和卸载

调整完成后点击「保存本机配置」，即可保存当前店铺、样式、舰船路线、取景、尺寸及格式，重新打开时恢复。常用配置与手动维护的图库存储在扩展自己的 IndexedDB 中，不与网站账号或其他设备同步。需要保留数据时，请使用同一 Edge 用户配置文件、同一扩展安装目录及同一扩展 ID。

更新时关闭生成器标签页，用新文件更新原目录，再在 `edge://extensions` 的扩展卡片中点击「重新加载」。不要先卸载。卸载、删除浏览器用户配置文件或清除扩展存储会丢失本机配置和个人图库；本版没有备份导入、导出功能。

已导出的图片、ZIP 和你自行保留的原始图片文件不随卸载删除。本版没有网站账号、留言板、远程管理员或网页抓取功能。
